# Medicare – Nadim Nauroz & Ferhad Ramazani

Statische Website für das gemeinsame Pflegeangebot von **Nadim Nauroz** und
**Ferhad Ramazani** (examinierte Pflegefachkräfte) innerhalb von Medicare Hamburg.
„Wir"-Ansprache, CI von medicare-hamburg.de (Anker-Logo, Teal + Navy).

## Seiten
- `index.html` – Startseite (Duo-Hero, Teams, Leistungen, Counter, Trust, Testimonials, FAQ, Tipps)
- `leistungen.html` – Leistungen, Pflegegrade & Sachleistungen 2026
- `kontakt.html` – Kontaktformular (Formspree)
- `danke.html` – Bestätigung nach Formularversand
- `praevention.html`, `pflegepolitik.html`, `digitalisierung.html` – Themenseiten
- `impressum.html`, `datenschutz.html` – Rechtstexte

## Vor dem Live-Gang noch zu erledigen
1. In `kontakt.html` die Formspree-ID (`YOUR_FORM_ID`) durch die echte ID ersetzen (Ziel-E-Mail nnauroz@live.de).
2. Impressum & Datenschutz durch die Geschäftsführung freigeben lassen; offene USt-IdNr. ergänzen.
3. Echte Testimonials statt der Platzhalter einsetzen.
